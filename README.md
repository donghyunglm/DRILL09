# Drill #9: 소년 상하좌우 이동 및 방향 바꾸기

## 실행

Python과 pico2d가 설치된 환경에서 실행합니다.

```powershell
python DRILL_9.PY
```

방향키: 상하좌우 이동. ESC 또는 창 닫기: 종료.
좌우 이동은 바라보는 방향을 변경하고, 상하 이동과 정지는 마지막 방향을 유지합니다.
정지 시 IDLE, 이동 입력 시 RUN 애니메이션을 사용합니다.
반대 방향키는 해당 축에서 상쇄되며 캐릭터 전체가 화면 안에 유지됩니다.

## 리소스

- animation_sheet.png: 100 × 100 프레임, 각 행 8프레임.
- 아래쪽부터 RUN_LEFT, RUN_RIGHT, IDLE_LEFT, IDLE_RIGHT.
- TUK_GROUND.png: 배경.
- 수업 예제는 과제 파일과 별도로 보존합니다.

## 검증

문법, 반복 키 입력, 반대 키 입력 및 해제, 상하 이동의 방향 유지,
IDLE 전환, 네 모서리의 경계, 프레임 범위, ESC 종료를 로직으로 확인했습니다.
실제 pico2d 창에서 이미지 로딩과 3프레임 렌더링 및 종료를 확인했습니다.
전체 애니메이션의 외관과 실제 키 조작감은 실행 창에서 직접 확인하세요.

## 이동 및 실행 안내 보완

- 방향키 두 개를 함께 눌러도 대각선 이동 속도는 한 방향 이동과 같습니다.
- 배경은 캔버스 전체 크기에 맞춰 표시합니다.
- 시작할 때 모든 방향키 입력 상태를 초기화합니다.
- 필수 이미지가 없으면 창을 열기 전에 누락된 파일 경로를 한국어로 안내합니다.
